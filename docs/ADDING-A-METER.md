### الصدر والعجز صورتان للبحر الواحد لا بحران

**لا تسجّل العجز بحرًا مستقلًّا.** سجّله صيغةً ثانية داخل البحر نفسه،
في مصفوفة `forms`. عندئذ يظهر البحر باسمه ونسبته لمن كتب شطرًا على
أيّ الصورتين — وهذا هو المقصود.

مثال: بحر تفعيلات صدره `فاعلاتن | فاعلاتن | فعولن`، وعجزه هو الصدر
نفسه مع تذييل التفعيلة الأخيرة (`فعولن` ← `فعولان`):

```json
{
  "id": "al_samri",
  "name": "السامري",
  "aliases": [],
  "enabled": true,
  "sourceIndex": 14,
  "forms": [
    {
      "role": "sadr",
      "feet": ["failatun", "failatun", "faulun"],
      "sourceQuote": "فاعلاتن فاعلاتن فعولن"
    },
    {
      "role": "ajz",
      "feet": ["failatun", "failatun", "faulan"],
      "sourceQuote": "فاعلاتن فاعلاتن فعولان"
    }
  ],
  "expectedSyllableCount": 11,
  "status": "OK"
}
```

الحقول:

| الحقل | إلزامي | معناه |
|---|---|---|
| `id` | نعم | معرّف لاتيني فريد، لا يتغيّر بعد ذلك |
| `name` | نعم | الاسم العربي كما يُعرض — **ولا يتكرّر** في القاعدة |
| `aliases` | نعم (ولو `[]`) | أسماء أخرى للبحر نفسه — تُستعمل في البحث. ضع هنا اسم أي مدخل دمجته |
| `enabled` | نعم | `false` يستبعده من المطابقة مع بقائه مسجَّلًا |
| `forms` | نعم | الصيغ: الصدر أولًا ثم العجز |
| `forms[].role` | نعم | `sadr` أو `ajz` |
| `forms[].feet` | نعم | معرّفات التفعيلات **لشطر واحد** لا لبيت كامل |
| `forms[].sourceQuote` | نعم | تفعيلات هذه الصيغة كما وردت في مصدرك حرفيًا |
| `expectedSyllableCount` | نعم | مجموع مقاطع تفعيلات **الصدر** — قيمة تحقّق |
| `status` | نعم | `OK` أو `NEEDS_VALIDATION` |
| `note` | إن كانت صيغة واحدة | تعليل غيابِ العجز — يشترطه اختبار |
| `duplicateOf` | إن طابق بحرًا آخر | معرّف البحر المطابق — يشترطه اختبار |

**إن لم يذكر مصدرك عجزًا، فلا تخترعه.** اكتفِ بصيغة الصدر وحدها،
وعلّل ذلك في `note`. المحرك يعمل على الصيغة الواحدة تمامًا؛ غاية الأمر
أنه لا يميّز شطري البيت.

**احسب `expectedSyllableCount` بجمع أطوال الأنماط**: فاعلاتن ٤ +
فاعلاتن ٤ + فعولن ٣ = ١١. إن أخطأت فشلت الاختبارات وأخبرتك بالرقمين —
وهذا مقصود، فهو يمنع تعريفًا يناقض نفسه.

الاختبارات المشتقّة من البيانات تلتقط بحرك الجديد تلقائيًا:

- «كل صيغة تطابق نمطها هي مطابقة تامة»
- «كل صيغة يتصدّر ترتيبَها بحرُها»
- «كل صيغة — صدرًا كانت أو عجزًا — تُظهر بحرها ودرجته»

- «لا اسمان متطابقان في القاعدة» و«كل اسم بديل يوصل إلى بحره»
- «لا بحران متطابقان إلا بإعلان صريح»

لم تكتب اختبارًا واحدًا، ومع ذلك صار البحر مغطّى — في التنفيذين معًا،
جافاسكربت وSwift.

## الحالة الثانية: البحر يحتاج تفعيلة غير موجودة

### الخطوة ١ — أضفها في `data/tafaeel.json`

عليك حساب حقلين. الطريقة:

**١. انطق التفعيلة مشكولةً وقسّمها مقاطع.**

مثال `مُتَفَاعِلُنْ`: مُ + تَ + فَا + عِ + لُنْ

**٢. اكتب كمّية كل مقطع:**

| المقطع | التركيب | الكمّية |
|---|---|---|
| مُ | صامت + حركة قصيرة | `S` |
| تَ | صامت + حركة قصيرة | `S` |
| فَا | صامت + حركة طويلة | `L` |
| عِ | صامت + حركة قصيرة | `S` |
| لُنْ | صامت + قصيرة + ساكن | `L` |

فالنمط `["S","S","L","S","L"]`.

**٣. اشتقّ النمط الحرفي**: كل `S` ← `1`، وكل `L` ← `10`، وكل `X` ← `100`.

`1` + `1` + `10` + `1` + `10` = `"1110110"`

**تحقّق**: عدد الأحرف يجب أن يساوي عدد حروف التفعيلة مشكولةً.
`مُتَفَاعِلُنْ` سبعة أحرف، و`1110110` سبعة رموز. ✓

```json
{
  "id": "mutafailun",
  "plain": "متفاعلن",
  "vocalized": "مُتَفَاعِلُنْ",
  "syllables": ["S", "S", "L", "S", "L"],
  "khalilLetters": "1110110",
  "components": ["فاصلة صغرى", "وتد مجموع"],
  "status": "STANDARD"
}
```

إن اختلف الحقلان أفشلت الاختبارات البناءَ وأرَتْك الرقمين. لا يمرّ
تعريف متناقض.

### الخطوة ٢ — أضف صورها في `variations.json`

**الحدّ الأدنى الصورة السالمة:**

```json
"mutafailun": [
  { "id": "salim", "name": "سالم", "result": "مُتَفَاعِلُنْ",
    "syllables": ["S","S","L","S","L"], "kind": "salim",
    "scope": "any", "severity": 1 }
]
```

ثم أضف ما تعرفه من زحافات وعلل:

| الحقل | القيم | متى |
|---|---|---|
| `kind` | `zihaf` | تغيير في الأسباب، جائز في الحشو |
| | `illa` | لازمة في العروض والضرب وحدهما |
| | `ambiguous_reading` | قراءتان مشروعتان لرسم واحد — ليست عيبًا |
| `scope` | `any` | الحشو والعروض والضرب |
| | `arud_darb` | العروض والضرب فقط |
| `severity` | `1` | شائع |
| | `2` | نادر أو ثقيل — كلفته أعلى |

**لا تخترع زحافات.** التفعيلة بصورتها السالمة وحدها تعمل تمامًا؛
غاية الأمر أن البحر يكون أشدّ صرامة. وهذا بالضبط حال التفاعيل
المذيَّلة والمقصورة كلها في القاعدة: لها الصورة السالمة وحدها، لأن
زحافاتها غير مسجَّلة في المصدر — وهي أصلًا صور عجز، والعلة لا تجتمع
مع علة.

## إن كان تعريف البحر غير مؤكَّد

لا تفعّله. سجّله بـ `enabled: false` وبيّن ما ينقص:

```json
{
  "id": "al_something",
  "name": "بحر ما",
  "enabled": false,
  "forms": [],
  "status": "NEEDS_VALIDATION",
  "derivation": {
    "why_not_implemented": "المصدر يصفه بكذا، وهو وصف غير قابل للتنفيذ",
    "candidates": [
      { "id": "reading_a", "feet": ["..."], "plausibility": "الأرجح لأن…" },
      { "id": "reading_b", "feet": ["..."], "plausibility": "ممكن لكن…" }
    ],
    "resolvedBy": "بيت واحد حقيقي مع تقطيعه"
  }
}
```

يظهر البحر عندئذ في تبويب «ما يحتاج تحقّقًا» في الصفحة وفي
`engine.openQuestions()`، ولا يشوّش المطابقة.

لا بحر معطَّل في القاعدة اليوم: القائمة الأخيرة أعطت تفعيلات صريحة
لكل بحر. لكن الباب مفتوح لبحر يصفه مصدرك وصفًا غير قابل للتنفيذ —
سجّله ولا تخمّنه.
